# نظام الدوام والمتابعة — مطاعم ريماس

تطبيق لإدارة الموظفين ومتابعة الدوام بالساعة (تعقيب)، مع التقارير والمخالفات والتقييم والإشعارات.

## المحتويات
- `www/index.html` — التطبيق كاملًا (ملف واحد).
- `.github/workflows/build-apk.yml` — بناء ملف APK تلقائيًا.
- `ci/debug.keystore` — مفتاح توقيع التطبيق (احتفظ بنسخة منه ولا تنشره).

## بناء APK
1. اذهب إلى تبويب **Actions** ثم **Build APK** ثم **Run workflow**.
2. بعد اكتمال البناء نزّل الملف المرفق `attendance-apk` وثبّته على الهاتف.

## تحديث التطبيق
1. استبدل `www/index.html` بالنسخة الجديدة.
2. شغّل **Build APK** من جديد وثبّت الملف الناتج فوق القديم (تبقى البيانات).

## المزامنة
المزامنة السحابية تتم عبر Google Apps Script (ملف `Code.gs`) ويُحفظ المفتاح السري في السكربت.
